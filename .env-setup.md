## 🐛 Troubleshooting

### Issue: "Supabase URL or Key is missing"
**Solution:**
1. Check `.env.local` exists in project root
2. Verify you have:
   - `VITE_SUPABASE_URL=`
   - `VITE_SUPABASE_ANON_KEY=`
3. Restart: `Ctrl+C` then `pnpm dev`

### Issue: "Can't sign up" / Auth errors
**Solution:**
1. Verify Supabase URL (no trailing slash)
2. Verify Anon Key is correct
3. Check database table `users` exists
4. Check RLS policies in Supabase

### Issue: "Stream not appearing"
**Solution:**
1. Check Supabase SQL Editor (data there?)
2. Verify status='live' in database
3. Check RLS policy allows SELECT for public

### Issue: "Agora token shows mock_token"
**Solution:**
1. Check `.env.local` has:
   - `AGORA_APP_ID=`
   - `AGORA_APP_CERTIFICATE=`
2. Verify values are NOT "your_xxx"
3. Restart server: `Ctrl+C` then `pnpm dev`

### Issue: "Network errors" / Can't connect
**Solution:**
1. Check dev server running: `pnpm dev`
2. Check port 8080 open: http://localhost:8080
3. Check backend logs for errors
4. Try browser refresh (Ctrl+Shift+R)
